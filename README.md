# East Midland Cars Limited

Next.js website scaffold.

## Folder structure

```
/
├── public/
│   └── favicon.svg
├── src/
│   ├── assets/
│   │   └── images/          # optimized content images (imported via next/image)
│   ├── components/
│   │   ├── Header.jsx
│   │   └── Footer.jsx
│   ├── layouts/
│   │   └── Layout.jsx
│   ├── app/
│   │   ├── layout.jsx
│   │   └── page.jsx
│   └── styles/
│       └── global.css
├── next.config.mjs
├── package.json
├── jsconfig.json
└── .gitignore
```

## Getting started

Install dependencies:

```
npm install
```

Run the development server:

```
npm run dev
```

Build for production:

```
npm run build
```

Start the production server:

```
npm start
```
